# Инструменты нарезки сериала (`/series-cut`)

Python-хелперы, которые вскрылись на втором сезоне «Кремниевой долины»
(ValleyRude … ValleyRuss). Запускать из корня репозитория, вывод — в UTF-8
(`PYTHONIOENCODING=utf-8` в Git Bash).

| Скрипт | Что делает |
|---|---|
| `requery_large.py <видео> <от> <до> [out.json]` | Переспрос фрагмента `whisper-large-v3` (Groq): печать сегментов в абсолютном времени, JSON со словами — для `index_insert.py`. Ключ `GROQ_API_KEY` из `.env`. |
| `gemini_listen.py <видео> <от> <до>` | Третий слух на спорную реплику — дословная расшифровка Gemini. |
| `index_words.py <slug> <от> <до>` | Реплики индекса с пословными таймингами: по ним ставятся границы битов. |
| `index_dedupe.py <slug>…` | Убирает слово-дубль на стыке соседних реплик (turbo кладёт одно слово в обе — в субтитре оно шло бы дважды). Прогонять по свежему индексу. |
| `index_insert.py <slug> <large.json> <after_id> <t0> <t1>` | Вставляет пропущенные turbo реплики из ответа large-v3 (id `<after>a, b, c…`), слова раскладывает по порядку. |
| `pan_override.py <Comp> <beat> <start> "cutA:cutB:x" …` | Траектория трекера бита с подменой участков планов: постоянный `x` или точки `src=x,…` по замерам `face_track.py`. Печатает TS-массив `pan`. |
| `pan_steps.py <Comp> <beat> <out.png>` | Полоски кадров ГОТОВОГО клипа вокруг каждой ступеньки окна: смена картинки и смена кропа обязаны совпасть. |

**Про ступеньки окна в AVI.** Поправка «на кадр раньше склейки» верна не всегда:
в одной серии одни склейки требуют её, другие — нет (метки кадров плавают).
Ставьте ступеньку по формуле, проверяйте `pan_steps.py` и двигайте точку
склейки на кадр (±0.042) в нужную сторону; если «рано» и «поздно» на соседних
значениях — ставьте середину (переключение у `cut-clips` чувствительно к
полукадру).
