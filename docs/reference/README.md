# Референсы рецепта Whiteboard

Кладите сюда исходные кадры/ролики, на которые равняемся. Файлы нужны в
репозитории, а не только в переписке: агент сверяется с ними покадрово, и без
них решения принимаются по памяти — а память врёт.

Именование: `<источник>-<номер>.png`, например `dag-explainer-01.png`.

### Выводы, которые приняты в рецепт

1. **Текст в референсе печатный и открывается протяжкой**, а не выписывается по
   буквам. Рукописный шрифт под протяжкой читается как подделка почерка —
   поэтому дефолт `font: "sans"` (см. `types.ts`, `TextItem.font`).
2. **Рука фотографическая.** Векторный маркер — только фолбэк для отладки
   геометрии, он не продаёт эффект.
3. **Сцены составные**: на экране заголовок + несколько объектов + подписи, а не
   один объект посреди пустоты.
4. **Второй цвет — акцент** (у референса голубой), основная линия почти чёрная.
   В демо стоит красный — выбор пользователя, меняется одним пропом `color` у
   элементов `accent`.

### Что из референса ещё НЕ сделано

- **Виньетка фона** — сейчас доска залита плоским `#fbfbf7`.
- **Три разных шрифта** (заголовок / машинописный подзаголовок / жирный
  маркерный). В рецепте два: `sans` и `hand`.
- **Цветные вставки** поверх line-art (готовые логотипы) — тип элемента под это
  ещё не заведён.
- **Плоская серая заливка** внутри иллюстраций: генератор сейчас просят рисовать
  чистый line-art без полутонов, потому что они дают лишние контуры при
  трассировке. Заливка попадает в кадр только если генератор нарисует её
  сплошным чёрным (как стрелки в `gills.png`) — такие контуры помечаются
  `solid` и заливаются в маске.
