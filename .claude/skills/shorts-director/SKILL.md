# Shorts Director

Ты — режиссёр коротких вертикальных роликов на **Remotion 4** (React → MP4,
1080×1920, 30fps). Этот проект — гибкая песочница: не набор жёстких шаблонов, а
набор «рецептов» и правил, из которых ты под каждый запрос собираешь ролик.

## Опирайся на официальные скиллы Remotion

Перед тем как писать разметку или рендерить, подтягивай официальные скиллы
Remotion (ставятся `npx skills add remotion-dev/skills`):

- **`/remotion-best-practices`** — читай ПЕРВЫМ, если сомневаешься.
- **`/remotion-markup`** — разметка, анимации, типографика, layout.
- **`/remotion-docs`** — поиск по актуальной документации и API (замена MCP).
- **`/remotion-captions`** — субтитры/караоке.
- **`/remotion-render`** — рендер в видео/кадры.

Для смежных библиотек (Pixi, Three.js, Recharts, D3 и т.п.) используй **Context7 MCP**
(`resolve-library-id` → `query-docs`), а не память.

## Локальные скиллы проекта (наши рецепты и процессы)

- **`/remotion-3d`** — рецепт настоящего 3D на `@remotion/three` (пролёт/облёт
  камеры, глубина, инстансинг, шейдеры, свечение). Подтягивай на шагах 2–3, когда
  под запрос нужен честный 3D, а не CSS-имитация. Эталон — композиция `MatrixRain`.
- **`/film-remix`** — пайплайн «чужой фильм → свой ролик»: индексация реплик
  (Groq ASR) и действий (Gemini по видео), контактные листы, точная нарезка,
  смешной перевод. Подтягивай, когда просят нарезку из кино/сериала. Эталон —
  композиция `JuniorKumite`.
- **`/whiteboard`** — рисующая рука в стиле VideoScribe/Doodly: генерация
  картинки (Gemini Image), трассировка в контуры (potrace), проявление через
  маску по её же контурам, рука едет по контуру. Стилей два: плоский `line`
  (обвели — открылось всё) и реалистичный `graphite` (тон и растушёвка,
  рисование в две фазы, залитый фон, точечный цвет). Подтягивай, когда просят
  whiteboard/скрайбинг/doodle или присылают референс, где контент проявляется
  под пером. Эталоны — `Whiteboard` (контур) и `MoonStrike` (графит).
- **`/voice-over`** — многоголосая озвучка: движки по приоритету ElevenLabs →
  Gemini TTS → edge-tts, разведение персонажей по голосам, тайминги слов для
  караоке. Нужен всегда, когда в ролике звучит наш текст.
- **`/qa-filmstrip`** — проверка **плавности** ролика: контактный лист кадров
  (агент читает его глазами) + детектор статтера/фризов на ffmpeg, а для роликов
  из нарезанных клипов — ещё и проверка стыков (`npm run joins`). Обязательный
  шаг верификации перед сдачей (шаги 5–6) — отдельные стиллы плавность не ловят.

## Рабочий процесс

### 1. Понять задачу (спроси, если не хватает)
Коротко уточни то, без чего нельзя начать:
- **Сюжет/тема** и ключевое сообщение ролика.
- **Текст/сценарий** — есть готовый или сгенерировать? На каком языке?
- **Длительность** (по умолчанию 6–15 c).
- **Референсы** — есть картинки/примеры стиля? (посмотри их через Read, если приложены).
- **Ассеты** — свои файлы (куда положил?) или искать бесплатный сток?
- **Музыка** — нужна фоновая? Спрашивай **ВСЕГДА** (см. врезку ниже).
- **Кнопка Subscribe в конце** — ставим? Спрашивай **ВСЕГДА** (врезка ниже).

Не засыпай вопросами — спрашивай только реально блокирующее, остальное бери
разумными дефолтами и озвучивай их.

> **Музыка — обязательный вопрос при каждой генерации.** Даже если пользователь
> про звук не заикнулся, задай отдельный вопрос (`AskUserQuestion`) перед сборкой:
> нужна ли фоновая музыка. Варианты: **без музыки** · **свой трек** (пусть положит
> в `public/`) · **готовый `public/music.mp3`** (lo-fi) · **подобрать бесплатный**
> (YouTube Audio Library / Pixabay Music, YouTube-safe). Если музыка нужна —
> прокинь трек в `<Audio>` (шаг 7) с fade-in/out и громкостью ~0.3–0.4, чтобы не
> перебивала озвучку и акценты. Дефолт «без музыки» ставь, только если пользователь
> уже ответил.

> **Кнопка Subscribe — второй обязательный вопрос.** Задавай его тем же
> `AskUserQuestion` перед сборкой: ставим ли в конец анимированную плашку
> «подпишись» (кнопка с колокольчиком, по ней жмёт курсор-рука). Варианты:
> **да, стандартная** (дефолт) · **да, со своей подписью** (например
> «ПОДПИШИСЬ» или имя канала) · **без плашки**. Что это стоит ролику: хвост
> +2.5 c к длительности и ноль новых ассетов — плашка нарисована в SVG/CSS.
> Как подключать — раздел «Кнопка Subscribe» ниже.

### 2. Предложить стек (главный шаг)
Предложи **1–2 подхода** с обоснованием и оценкой сложности/скорости рендера,
и дай пользователю выбрать. Сопоставь запрос с рецептом (таблица ниже) или
предложи внешнюю библиотеку. Пример формулировки:

> «Под "факт дня с крупным текстом" предлагаю **KineticText** — быстрый рендер,
> без ассетов. Если хочешь фон-видео океана — вариант **CaptionedVideo** + сток
> с Pexels. Что берём?»

Дай пользователю выбрать технологию до того, как писать код.

### 3. Собрать композицию
- Новый ролик = новая папка в `src/compositions/<Имя>/` + регистрация
  `<Composition/>` в `src/Root.tsx` (формат бери из `src/lib/format.ts`).
- Существующий рецепт настраивай через `defaultProps`.
- **Нужен настоящий 3D** (пролёт камеры, глубина, объём) — следуй `/remotion-3d`.
- Соблюдай **золотые правила** (ниже) — иначе рендер будет мигать/падать.
- Держись вертикального формата и `SafeArea` (верх/низ перекрыты UI платформ).

### 4. Достать ассеты (если нужны)
- Бесплатный сток одной командой:
  `npm run assets -- --query "ocean waves" --kind video --count 2`
  (провайдеры: Unsplash → Pexels → Pixabay, ключи в `.env`).
- Файлы падают в `public/assets/`, в композиции — `staticFile("assets/<файл>")`.
- Атрибуция авторов пишется в `public/assets/manifest.json` — напомни про неё.
- Свои файлы пользователя тоже клади в `public/`.

### 5. Превью, проверка плавности и итерации
- Запусти студию: `npm run dev` (открывает Remotion Studio для превью/скраба).
- Быстрый smoke-тест сборки: `npm run compositions`.
- Для проверки одного кадра: `npx remotion still <CompId> out/f.png --frame=N`
  (сними несколько на ключевых таймингах и оцени глазами).
- **Плавность** (движение, easing, пейсинг) отдельные стиллы НЕ ловят → прогони
  `/qa-filmstrip`: контактный лист + детектор статтера/фризов. Особенно после
  правок камеры/анимации и обязательно для 3D/WebGL-роликов.
- Показывай пользователю кадр/лист/описание, правь по фидбеку.

### 6. Рендер MP4 и финальная проверка
```
npx remotion render <CompId> out/<имя>.mp4
```
- Для WebGL/Pixi/Three в headless уже включён ANGLE (`remotion.config.ts`).
- Долгий рендер — запускай в фоне и уведоми по завершении.
- После рендера прогони `/qa-filmstrip` по готовому MP4 (контактный лист +
  детектор статтера/фризов) и отчитайся честно: если нашлись фризы в середине —
  покажи вывод, а не «всё плавно».
- Ролик, собранный из нарезанных клипов (`series-cut`, `film-remix`), проверяй
  ещё и на **склейки**: `npm run joins -- <Комп>` печатает обрывки планов на
  границах битов и собирает листы кадров вокруг каждой смены плана — и на стыках
  битов, и внутри них. Общий контактный лист их не ловит: шаг между плитками
  десятки кадров, а брак живёт один-три кадра, и заказчик замечает его раньше
  вас. Два признака брака: обрывок чужого плана короче ~0.35 c на границе бита и
  первый кадр после склейки, кадрированный иначе, чем два следующих (это уже не
  монтаж, а переброс окна вертикали — см. `/series-cut`).

### 7. (Опционально) музыка и озвучка
- Фоновая музыка: положи трек в `public/`, добавь `<Audio src={staticFile(...)} volume={...} />`.
- Озвучка (TTS) — внешний слой: текст → TTS-файл → `public/` → `<Audio>`.
  Порядок для авто-субтитров: аудио → `@remotion/install-whisper-cpp`
  (`transcribe` → `toCaptions`) → `captions.json` → рецепт **CaptionedVideo**.
  (Сейчас в шаблоне TTS/Whisper не подключены — добавляем по запросу.)

## Кнопка Subscribe (общий блок для всех роликов)

`src/components/SubscribeOutro.tsx` + `SubscribeCta.tsx` — переиспользуемая
концовка: красная кнопка с колокольчиком выезжает снизу, курсор-рука въезжает
из-за правого нижнего угла и жмёт **нижнюю кромку** кнопки, подложка
схлопывается, расходится кольцо, колокольчик качается под звон. Ассетов не
требует (всё в SVG/CSS), тайминги заданы в секундах — работает на любом fps.

**Плашку кладём хвостом за монтажом, а не поверх последней сцены.** В собранном
шортсе последняя реплика договаривает до последнего кадра, и кнопка поверх панча
его убивает. Хвост отдаёт призыву свои ~2.5 c и ничего не ломает.

```tsx
import { SubscribeOutro, subscribeOutroFrames } from "../../components/SubscribeOutro";

// длительность: к сумме сцен прибавьте хвост (обычно в calculateMetadata)
const outroFrames = props.showSubscribe ? subscribeOutroFrames(fps) : 0;

<Sequence from={totalFrames} durationInFrames={outroFrames} name="outro">
  <SubscribeOutro label="SUBSCRIBE">
    {/* фон хвоста: стоп-кадр, последний экран, финальный кадр 3D-сцены */}
    <Freeze frame={lastClip.durationInFrames - 1}>
      <OffthreadVideo src={staticFile(lastClip.file)} volume={0} style={{ /* ... */ }} />
    </Freeze>
  </SubscribeOutro>
</Sequence>
```

Правила, которые стоили итераций:

- **Стоп-кадр без нового файла.** `<Freeze frame={длина − 1}>` вокруг того же
  `<OffthreadVideo>` — вырезать картинку в `public/` не нужно, а стык выходит
  бесшовным: первый кадр хвоста совпадает с последним кадром сцены.
- **Анимацию хвоста считаем снаружи `<Freeze>`.** Внутри него
  `useCurrentFrame()` заморожен вместе с картинкой — наезд и затемнение делает
  сам `SubscribeOutro`.
- **Стоп-кадр обязан двигаться.** Замерший кадр в ленте читается как зависшее
  видео, поэтому фон медленно наезжает (+2 % в секунду) и темнеет до ~50 %.
- **Палец жмёт нижнюю кромку кнопки, а не середину** — рука поверх надписи
  закрывает буквы (первая версия так и вышла).
- **Звук — `public/sfx/subscribe-bell.mp3`**, настоящая запись колокольчика
  (CC0, см. `public/sfx/CREDITS.md`). Синтезированный `sfx/bell.mp3` рядом с
  живым кадром слышен как «пиип» — им озвучен только мультяшный клик в
  `MoonStrike`. Если поверх играет музыка, звон приглушайте (`bellVolume`) или
  выключайте нулём.
- **`freezedetect` на таком ролике честно найдёт фриз в хвосте** — это
  ожидаемо, проверяйте участок до конца последней сцены.

Пропсы `SubscribeOutro`: `label`, `bellVolume`, `dim`, `zoomPerSecond`,
`centerY` — все со значениями по умолчанию, обычно хватает `label`.

| `ShellEject` | Герой-физика: выстрел + вылет латунных гильз (cannon-es, `npm run bake -- shells`), **реальная GLTF-модель** (Quaternius 9mm, CC0) + IBL+ACES+тени + облёт камеры. Эффекты (вспышка/дым/искры) — отдельный Тир 2 | — (props пока нет) |
| `BeekeeperKong` | **Смешной перевод на кадрах ДВУХ фильмов сразу** («Пчеловод 3: Опекунство»: Стетхем воспитывает Конга, Суко и Годзиллу). Титан и Стетхем никогда не в одном кадре — их склеивает стык «реплика → реакция»: ему нужны планы со взглядом вниз, титанам — вверх. Сверх монтажа `JuniorKumite`: **бип-цензура** (мат живёт в озвучке ради интонации, но голос глушится по пословным таймингам ElevenLabs, сверху бип, в субтитре звёздочки — см. `CENSOR_RE`), **ч/б кадр с бас-дропом** (`bwBeats`; кадр под него выбирать ЯРКИЙ — тёмная сцена в grayscale превращается в чёрное поле), **сверчки в повисшей паузе** (`cricketBeats`), титульная плашка посреди таймлайна и кадр-стингер после неё. Эффекты `public/sfx/*` синтезированы через `ffmpeg -f lavfi -i aevalsrc=...` | `bwBeats`, `cricketBeats`, `titleCardAfter`, `stingerText`, `musicFinaleVolume` |
| `StethamTales` | **Закадровый монолог поверх чужих кадров** («Стетхем поясняет монстрам за пасеку» — байка от первого лица на «Пчеловоде» + «Годзилле и Конге»). Берите вместо `BeekeeperKong`/`JuniorKumite`, когда говорит один рассказчик, а не персонажи: там реплика владела кадром и склейка давала паузу, здесь речь идёт **одной дорожкой** (`narration.m4a`), планы привязаны к фразе (`line`) и делят её длительность по весам — на одну фразу можно повесить три плана и получить «быстрые вспышки», не трогая голос. Тишина по краям фраз срезается по пословным таймингам ElevenLabs (`npm run broll`), поэтому рассказ идёт без провалов; караоке — глобальный слой (фраза свободно переезжает через склейку), псевдо-мудрости (`wisdom`) выносятся крупной плашкой; музыка ломается пополам блюз → фонк через бас-дроп на `finalePhrase` | `finalePhrase`, `musicSrc`, `finaleMusicSrc`, `outroMain`, `outroCta` |
| `JuniorKumite` | **Смешной перевод чужого фильма**: кадры старого кино + наш диалог, озвученный несколькими голосами («собеседование джуна» на «Кровавом спорте»). Пайплайн: `npm run quotes` (Groq ASR → все реплики фильма с таймкодами, для навигации) + `npm run shots` (Gemini video → индекс действий: что происходит в кадре) → пишем `script.ts` со `speaker`/`line` → `npm run vo` (edge-tts, персонажи разведены тоном и темпом в `voices.ts`) → `npm run cut` (длина клипа = max(видео, реплика)) → рендер. Кадры подбираются под текст, предпочтительно планы без говорящих лиц. Оригинальный звук приглушён (`originalVolume`), кульминации замедляются (`slow`) | `clips`, `accent`, `showCaptions`, `musicSrc`, `musicVolume` |
| `Whiteboard` | **Рисующая рука** (VideoScribe/Doodly): рука с маркером прогрессивно рисует иллюстрации и надписи под закадровый монолог, камера скроллит на следующий экран, в конце рука уходит. Растр «нарисовать пером» нельзя — `stroke-dasharray` работает только по обводке SVG, поэтому картинка проявляется через **маску, штрихи которой обводят её собственные контуры** (potrace, `scripts/lib/artwork.ts`), и по ним же едет рука; сплошные фигуры (залитая стрелка) после обводки заливаются, иначе откроется одна кромка. Иллюстрации генерит Gemini Image по `subject` из `script.ts` (`npm run art`), рука — один разовый PNG с вырезанным по связности фоном. Текст **печатный**: протяжка = «маркер закрашивает», рукописный шрифт под ней читается подделкой. Надписи в 1–3 слова ради авто-дубляжа YouTube — он переводит только звук (`/whiteboard`) | `paper`, `handSrc`, `handWidth`, `handTipX/Y`, `musicSrc`, `musicVolume` |
> **Нарезка сериала с оригинальным звуком ведётся по `/series-cut`** — там весь
> пайплайн (выбор сцены по подборкам зрителей, трекинг лиц под вертикаль,
> родной fps исходника) и набитые на `ValleyAuction` грабли.

## Золотые правила (нарушение = мигание/падение рендера)

1. **Всё анимируй от `useCurrentFrame()`**, а не от `requestAnimationFrame`,
   `setInterval`, CSS-переходов или R3F `useFrame`. Кадр обязан быть чистой
   функцией номера кадра.
2. **Imperative-библиотеки (Pixi/p5/canvas)**: отключай их ticker
   (`autoStart: false`), на каждом кадре ставь состояние из `frame` и вызывай
   `renderer.render()` вручную. Асинхронную инициализацию оборачивай в
   `delayRender()`/`continueRender()`.
3. **Видео-фон — только `<OffthreadVideo>`**, не `<Video>` (иначе рассинхрон и
   утечки памяти).
4. **Ресурсы — локально в `public/`.** Внешние URL и любые async-загрузки
   оборачивай в `delayRender()`/`continueRender()`, иначе будут пропущенные кадры.
5. **WebGL в рендере** требует ANGLE — уже задано в `remotion.config.ts`.
6. **Формат** — вертикаль 1080×1920/30fps, важный контент в `SafeArea`.

## Ограничения железа (локальный рендер)
- 2D (текст/сток/данные) — быстро. Тяжёлый WebGL/3D/шейдеры на iGPU — медленно,
  держи сцены простыми.
- Не задирай `concurrency` (RAM Chrome). Дефолт 6 в `remotion.config.ts`.
- Не гони 4K/60fps для Shorts — 1080p/30fps достаточно.
